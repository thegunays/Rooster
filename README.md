1. Purpose and Data Flow
   `New → Rooster → System.Description → Details / Design (Tasarım)`

2. Installation of the `0.1.XX` VSIX package

3. Navigate to **Process → SRS → Layout**

4. Add the **Rooster custom control**

5. Configure **Options**:

   * `FieldName = Description`
   * `EnabledWits = SRS`
   * Keep the optional fields at their default values

6. Configure **Layout**:

   * Page: `New`
   * Label: `Design (Tasarım) - Rooster`
   * Select the appropriate group

7. Save the configuration and perform a functional test
